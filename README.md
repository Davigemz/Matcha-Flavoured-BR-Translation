# **Matcha Flavoured Localizado em PT-BR**
Uma Localização não oficial para o Português Brasileiro do Datapack [Matcha Flavoured](https://modrinth.com/datapack/matcha-flavoured) feito por **klei_wright**!

Esta Localização tenta ao máximo se aproximar da linguagem oficial do Minecraft, também tentando ao máximo ser semelhante à linguagem usada no Datapack.

Essa Localização é baseada na [Fork](https://github.com/imtlx/matcha-flavoured-localization) do datapack feita por **imtlx**.
