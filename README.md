# Matcha Flavoured: Localization Edition

A unofficial fork of [**Matcha Flavoured**](https://modrinth.com/datapack/matcha-flavoured) by **Klei Wright** with **Ukrainian** and **Russian** localization support.

The original project already supports localization in most places through Minecraft's translation system. This fork completes that support by replacing the remaining hardcoded text with translation keys and providing translations.

## Features

- 🇺🇦 Ukrainian localization
- 🇷🇺 Russian localization
- Localized advancement titles and descriptions
- Added translation keys where hardcoded text prevented localization
- Localization support throughout the datapack

## Why this fork?

The original datapack already uses Minecraft translation keys for most text. However, some components still used hardcoded `"text"` values instead of `"translate"` keys, preventing them from being localized.

This fork replaces those hardcoded strings with translation keys where appropriate and provides Ukrainian and Russian translations, while preserving the original gameplay.
